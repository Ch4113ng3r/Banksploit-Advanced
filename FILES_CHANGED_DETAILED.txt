ARCHITECTURE: HOW ROLE IS PROPAGATED
===============================================================================

VULNERABLE FLOW (JWT alg:none):
  Forged JWT: {role: "admin", alg: "none"}
    ↓
  auth()->getCurrentUser()
    ↓
  jwtUser() verifies JWT
    ↓
  verifyJWT() accepts alg:none at vuln level 0
    ↓
  Returns: claims with role="admin"
    ↓
  auth()->isAdmin() checks: role === "admin" ✓
    ↓
  layout.php: $showAdmin = true
    ↓
  Admin tab SHOWS [VULNERABILITY IN ACTION]

SECURE FLOW (JWT HS256, level 3):
  Forged token rejected by verifyJWT()
    ↓
  auth()->getCurrentUser() returns null
    ↓
  auth()->isAdmin() returns false
    ↓
  Admin tab hidden [SECURE]
