📋 WHAT'S AVAILABLE
════════════════════════════════════════════════════════════════════════════

BULK REPLACE TAB:
  Format A (Auto-Match):
    • 2-column CSV: Customer ID, Full Name
    • System finds next available slot automatically
    • Example: G01197938, Alice Johnson
    • Use for: Walk-in staff, fastest option

  Format B (Manual):
    • 3-column CSV: Old ID, New ID, New Name
    • You specify which user to replace
    • Example: BS100300, STAFF001, Alice Johnson
    • Use for: Reassignments, known users

SINGLE REPLACE TAB:
  Mode A (Auto-Match):
    • Enter staff ID + name
    • System auto-selects next slot
    • Shows slots remaining
    • Use for: Individual walk-ins

  Mode B (Manual):
    • Select user from dropdown
    • Enter new ID + name
    • Works even if slots exhausted
    • Use for: Reassignments, flexibility

📊 FORMAT COMPARISON
════════════════════════════════════════════════════════════════════════════

FORMAT A (Auto-Match):
  • Columns: 2 (Customer ID, Full Name)
  • Format: Barclays only (G/B/H/E + 8 digits)
  • Speed: Fastest
  • Requires: Available slots
  • Error: If all slots used → "Switch to Manual Mode"

FORMAT B (Manual):
  • Columns: 3 (Old ID, New ID, New Name)
  • Format: Any customer_id
  • Speed: Normal
  • Requires: Nothing (no slots, always works)
  • Error: If old ID not found

🚀 TYPICAL WORKFLOW
════════════════════════════════════════════════════════════════════════════

Pre-Session Setup:
  1. Create 100 bulk users: /bulk-import
  2. Prepare staff CSV with Barclays IDs
  3. Upload via Format A (auto-match)
  4. Verify all replaced: 100 successful, 0 failed

During Session:
  Single walk-in arrives:
    → Mode A: Enter ID + name, click "Replace Next Slot"
    → Done! (auto-selected which BS user replaced)

Multiple staff need reassignment:
  → Use Format B
  → Upload CSV with old IDs (BS100350, etc.)
  → New staff IDs (G01197938, etc.)
  → Upload and done


⚠️ COMMON SCENARIOS
════════════════════════════════════════════════════════════════════════════

"All slots are used, but staff arrived!"
  → Use Mode B (Manual)
  → Select existing user from dropdown
  → Replace with new staff ID
  → No "slots exhausted" error

"I want to swap one specific user"
  → Use Mode B (Manual)
  → Select that user
  → Enter new ID + name
  → Done

"I have 50 Barclays IDs to import"
  → Use Format A (Auto-Match)
  → Create CSV: Customer ID, Full Name
  → Upload
  → 50 replaced automatically

"I need to change one user's name"
  → Use Mode B (Manual)
  → Select user
  → Leave old ID blank
  → Enter new name only
  → Saves just the name


❌ ERROR HANDLING
════════════════════════════════════════════════════════════════════════════

"Invalid Barclays ID format"
  → Format must be: G/B/H/E + 8 digits
  → Example: G01197938 (correct)
  → Example: G017938 (wrong - only 6 digits)

"All 100 pre-created slots are used"
  → Switch to Mode B (Manual)
  → Select user you want to replace
  → Enter new ID + name

"Customer ID already exists"
  → That ID is already in database
  → Use a different ID
  → Or use Mode B to replace existing

"Old Customer ID not found"
  → User doesn't exist
  → Check spelling
  → Verify BS ID is BS100300-BS100399
