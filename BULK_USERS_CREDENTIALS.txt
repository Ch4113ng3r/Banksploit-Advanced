TROUBLESHOOTING LOGIN ISSUES
============================

Problem: "Invalid Customer ID"
  → Make sure you're using BS10030X format (6 digits after BS)
  → Example: BS100300 (not BS100300 typed twice)

Problem: "Invalid Password"
  → Format is: {customerid} + B4rc + @ + 123
  → Example: BS100300B4rc@123
  → Check: No spaces, exact capitalization (B and c capitalized)

Problem: "OTP not received"
  → In Lab Mode: OTP is shown on the login screen
  → In Secure Mode: Query database: SELECT otp_code FROM otp_tokens LIMIT 1;
  → Or reset: Log out and try again (new OTP generated per login)

Problem: "Account not found"
  → Verify DB setup: ./start.sh setup
  → Check: php src/scripts/verify_bulk_users.php
  → Restart app: ./start.sh stop && ./start.sh start

DATABASE QUERIES
================

View all bulk users:
  SELECT customer_id, name, email FROM users WHERE customer_id LIKE 'BS1003%';

View user with accounts:
  SELECT u.customer_id, u.name, COUNT(a.id) as account_count
  FROM users u LEFT JOIN accounts a ON u.id = a.user_id
  WHERE u.customer_id LIKE 'BS1003%'
  GROUP BY u.id;

View user with all related data:
  SELECT
    u.customer_id,
    (SELECT COUNT(*) FROM accounts WHERE user_id = u.id) as accounts,
    (SELECT COUNT(*) FROM cards WHERE user_id = u.id) as cards,
    (SELECT COUNT(*) FROM beneficiaries WHERE user_id = u.id) as beneficiaries,
    (SELECT COUNT(*) FROM security_questions WHERE user_id = u.id) as security_qs
  FROM users u
  WHERE u.customer_id = 'BS100300';
