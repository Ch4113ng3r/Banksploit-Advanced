COMMON QUESTIONS
================================================================================

Q: Will command injection still work for users?
A: Yes! Users can still solve the G9 challenge, but it's sandboxed.
   They can run: cat flag_g9_[userid].txt
   They CANNOT run: cat /etc/passwd (no access outside sandbox)

Q: Why is application fast now?
A: Query caching is enabled (32MB) + binary logging disabled.
   Frequent queries return from cache, not disk.

Q: Can users connect to database directly?
A: No, MySQL only listens on 127.0.0.1.
   Port 3306 is not exposed to network.

Q: How do I know security is applied?
A: Run: netstat -ano | findstr "3306" | findstr -v "33060"
   Should show: TCP 127.0.0.1:3306 LISTENING (not 0.0.0.0)

Q: What if MySQL doesn't restart?
A: Check if MySQL84 service exists:
   Get-Service MySQL84
   If missing, reinstall MySQL from windows installer.
