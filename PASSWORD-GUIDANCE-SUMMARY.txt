🎓 USER FLOWS
════════════════════════════════════════════════════════════════════════════

ADMINISTRATOR WORKFLOW
  1. Navigate to Replace Users interface
  2. Choose replacement mode (Bulk, Mode A, or Mode B)
  3. See password template guidance on screen
  4. Enter Customer ID (e.g., G01197938)
  5. System auto-generates password using template
  6. Password stored in database (bcrypt + MD5)

PARTICIPANT WORKFLOW
  1. Receive replacement confirmation with Customer ID
  2. See password information on login page/confirmation
  3. Password follows pattern: {TheirID}B4rc@123
  4. Login with Customer ID and password
  5. Can change password after first login


📊 PASSWORD STRENGTH
════════════════════════════════════════════════════════════════════════════

Example: G01197938B4rc@123

Length:           18 characters (strong)
Uppercase:        G (customer ID specific)
Lowercase:        r, c (from B4rc)
Numbers:          0, 1, 9, 7, 3, 8, 1, 2, 3 (very mixed)
Special Chars:    @ (one)
Complexity:       STRONG ✓
Memorable:        YES (ID + pattern)
Unique:           YES (per customer)

📞 QUICK SUPPORT RESPONSE
════════════════════════════════════════════════════════════════════════════

Q: "What's my password?"
A: Your password is your Customer ID + "B4rc@123"
   Example: If your ID is G01197938, password is G01197938B4rc@123

Q: "Can I change my password?"
A: Yes, after you login, go to Settings/Profile and change it

Q: "I forgot my password"
A: Your password is {YourCustomerID}B4rc@123. Check your ID in the
   confirmation email or contact admin.

Q: "Why is the password in that format?"
A: It's a standard pattern to make it easy to remember. See the password
   guidance box in the Replace Users interface.

Q: "Can we use custom passwords?"
A: No, passwords are auto-generated from your Customer ID. You can
   change it to something custom after your first login.
