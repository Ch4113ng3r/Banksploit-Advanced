📞 SUPPORT
═══════════

Quick Troubleshooting:
  1. Check error message — usually very specific
  2. Verify CSV format matches expected columns
  3. Ensure old customer IDs exist in database
  4. Check for duplicate customer IDs
  5. Run verification script: php src/scripts/verify_bulk_replace.php

Common Issues & Fixes:

  Issue:  "Column not found"
  Fix:    Verify CSV headers match exactly
          (Old Customer ID, New Customer ID, New Full Name)

  Issue:  "Customer ID already exists"
  Fix:    Check database for duplicate
          Make sure new ID is unique

  Issue:  Single user dropdown empty
  Fix:    Create bulk users first with /bulk-import
          Then use Replace Users to modify them

  Issue:  Changes not showing
  Fix:    Hard refresh browser (Ctrl+Shift+R)
          Close/reopen control panel
