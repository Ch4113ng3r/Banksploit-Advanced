DUPLICATE DETECTION
═══════════════════

Validates Customer ID Uniqueness in 3 Ways:

1. WITHIN FILE (Bulk Replace)
   ────────────────────────
   Each new customer ID must be unique within the upload

   Example rejection:
   Row 1: BS100300 → STAFF001 ✓
   Row 2: BS100301 → STAFF002 ✓
   Row 3: BS100302 → STAFF001 ✗ Error: "Duplicate in file (row 1)"

2. AGAINST DATABASE (Both)
   ──────────────────
   New customer ID must not exist in database (unless it's the old ID)

   Example rejection:
   User wants: BS100300 → STAFF001
   Database check: STAFF001 exists!
   Result: ✗ Error: "Customer ID already exists"

3. SINGLE USER (Single Replace)
   ────────────────────────
   Additional check: Old customer must exist

   Example rejection:
   Select: BS999999 (doesn't exist)
   Result: ✗ Error: "Customer ID not found"


VALIDATION ERRORS
═════════════════

All errors are specific and actionable:

Bulk Replace:
  • "Old Customer ID 'BS100300' not found in database."
  • "New Customer ID 'STAFF001' already exists in database."
  • "Duplicate Customer ID in file (row 2)."
  • "[Field name] is required."
  • "Only .csv and .xlsx files are supported."
  • "File is empty or could not be parsed."

Single User:
  • "Customer ID '[ID]' not found."
  • "Customer ID '[ID]' already exists in database."
  • "Provide at least a new Customer ID or Full Name."
  • "CSRF token invalid."
