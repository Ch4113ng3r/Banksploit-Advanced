5. INSTANT EFFECT - No restart needed!

📊 AVAILABLE FEATURES
════════════════════════════════════════════════════════════════════════════

1. training_lab (Default: ON)
   • Disables: /training, /lab, /training/code, /inspector
   • Effect: "🔒 Training Lab is Disabled"
   • Use: Hide CTF challenges during event setup

2. leaderboard (Default: ON)
   • Disables: /leaderboard page
   • Effect: "🔒 Leaderboard is Disabled"
   • Use: Hide scores during active competition

3. flag_submission (Default: ON)
   • Disables: /api/v1/training/submit-flag
   • Effect: HTTP 403 "Flag submission is currently disabled"
   • Use: Prevent early point gathering

4. code_inspector (Default: ON)
   • Disables: /inspector (request logs)
   • Effect: "🔒 Feature Disabled"
   • Use: Hide request/response inspector

5. swagger_docs (Default: ON)
   • Disables: /swagger-ui (API documentation)
   • Effect: HTTP 403 "API documentation is currently disabled"
   • Use: Force API discovery through exploration

6. debug_mode (Default: OFF)
   • Enables: /debug/session, /debug/api
   • Effect: Debug endpoints become accessible
   • Use: Troubleshooting issues only

7. otp_display (Default: ON)
   • Disables: OTP display on login page
   • Effect: Participants must find OTP via API/database
   • Use: Challenge mode (no convenient OTP)

8. request_logging (Default: ON)
   • Disables: HTTP request logging
   • Effect: /inspector becomes empty, less database load
   • Use: Performance optimization

🔄 HOW IT WORKS
════════════════════════════════════════════════════════════════════════════

Architecture:

  Instructor Portal (8888)  →  Toggle Click  →  MySQL Update
         ↓
     /features page
         ↓
     [Toggle] button
         ↓
     POST /features
         ↓
     Verify CSRF
         ↓
     UPDATE feature_toggles
         ↓
     Response with new state
         ↓
  ↓
  CTF App (9443)
     ↓
  Middleware: is_feature_enabled()?
     ├─ YES: Allow request
     └─ NO: Block with 403

Request Flow:

  User: GET /training
       ↓
  Middleware: is_feature_enabled('training_lab')?
       ├─ TRUE: Route to /training (normal)
       └─ FALSE: Return 403 "Training Lab is Disabled"

💾 DATABASE MANAGEMENT
════════════════════════════════════════════════════════════════════════════

Table: feature_toggles

  Column         | Type         | Description
  ───────────────┼──────────────┼───────────────────────────────
  feature_key    | VARCHAR(50)  | Primary key: 'training_lab', etc
  is_enabled     | BOOLEAN      | 1 = ON, 0 = OFF
  description    | VARCHAR(255) | "Disable /training page"
  updated_at     | TIMESTAMP    | Last toggle time

View All Features:
  SELECT feature_key, is_enabled, description, updated_at
  FROM feature_toggles;

Enable Feature Manually:
  UPDATE feature_toggles SET is_enabled = 1
  WHERE feature_key = 'training_lab';

Disable Feature Manually:
  UPDATE feature_toggles SET is_enabled = 0
  WHERE feature_key = 'leaderboard';

Reset All to Defaults:
  UPDATE feature_toggles SET is_enabled = 1;
  UPDATE feature_toggles SET is_enabled = 0
  WHERE feature_key = 'debug_mode';
