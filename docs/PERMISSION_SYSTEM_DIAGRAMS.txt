DIAGRAM 6: PERMISSION CHECK IN ALL COMMANDS
================================================================================

Command Implementations and Where Permission Check Occurs:

cmdCat (line 117-141)
  ├─ For each file argument
  │  ├─ Resolve path
  │  ├─ [CHECK] isOtherUserFlagFile(basename) → BLOCK if true
  │  ├─ Check file exists
  │  └─ Return content

cmdLs (line 143-180)
  ├─ Determine target directory
  ├─ Scan directory
  ├─ For each entry
  │  ├─ [CHECK] isOtherUserFlagFile(entry) → SKIP if true
  │  └─ Add to listing
  └─ Return listing

cmdHead (line 206-241)
  ├─ Parse arguments
  ├─ For each file
  │  ├─ Resolve path
  │  ├─ [CHECK] isOtherUserFlagFile(basename) → BLOCK if true
  │  ├─ Check file exists
  │  └─ Return first N lines

cmdTail (line 243-278)
  ├─ Parse arguments
  ├─ For each file
  │  ├─ Resolve path
  │  ├─ [CHECK] isOtherUserFlagFile(basename) → BLOCK if true
  │  ├─ Check file exists
  │  └─ Return last N lines

cmdWc (line 280-307)
  ├─ Get file list
  ├─ For each file
  │  ├─ Resolve path
  │  ├─ [CHECK] isOtherUserFlagFile(basename) → BLOCK if true
  │  ├─ Check file exists
  │  └─ Count lines/words/bytes

Pattern: ✓ All file access operations check permissions before reading

DIAGRAM 8: VULNERABILITY WITH ISOLATION
================================================================================

Without Per-User Flag Isolation:

Timeline 1: Single user (OK)
  T=0s: User A triggers exploit
        → /tmp/flag_g9.txt created (ONE flag file!)
        → User A reads: cat /tmp/flag_g9.txt → SUCCESS

Timeline 2: Multiple users (BROKEN)
  T=0s: User A triggers exploit
        → /tmp/flag_g9.txt created
        → Contains Flag_A
  T=1s: User B triggers exploit
        → /tmp/flag_g9.txt OVERWRITTEN
        → Contains Flag_B (replaced!)
  T=2s: User A tries to read
        → cat /tmp/flag_g9.txt
        → Gets Flag_B (WRONG!) ✗
  T=3s: User A submits Flag_B
        → System credits User A with Flag_B exploit
        → But Flag_B belongs to User B!
        → CTF integrity BROKEN ✗


With Per-User Flag Files (CORRECT):

  T=0s: User A triggers exploit
        → /tmp/flag_g9_1.txt created
        → Contains Flag_A_Only
  T=1s: User B triggers exploit
        → /tmp/flag_g9_2.txt created
        → Contains Flag_B_Only (different file!)
  T=2s: User A tries to read
        → cat /tmp/flag_g9_1.txt
        → Gets Flag_A (CORRECT) ✓
  T=3s: User B tries to read
        → cat /tmp/flag_g9_2.txt
        → Gets Flag_B (CORRECT) ✓
  T=4s: User A tries to read User B's flag
        → cat /tmp/flag_g9_2.txt
        → Permission denied (PROTECTED) ✓
  T=5s: Each user submits their own flag
        → User A gets credit for Flag_A exploit ✓
        → User B gets credit for Flag_B exploit ✓
        → CTF integrity MAINTAINED ✓
